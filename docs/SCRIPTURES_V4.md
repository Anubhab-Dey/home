## Deployment/repository separation

Deployment is from a Windows PowerShell 7 temporary workspace and uses the host's existing SSH alias `hostinger-vps`. The change package is an overlay, not a replacement of the entire site. The release uploader downloads the PDF to Windows over validated HTTPS, verifies basic file identity and size, uploads a tiny update bundle to the VPS, copies the live site into a sibling staging directory, overlays changed assets and the PDF, checks the result, switches live directories, checks local Caddy responses, and cleans up all temporary artifacts after success. No GitHub account is accessed. The user independently imports these changed source files into their personal repository `Anubhab-Dey/home` later.

After launch, test directly in a normal web browser on desktop and mobile, including PDF opening, file download, book readers and source-desk filtering.
